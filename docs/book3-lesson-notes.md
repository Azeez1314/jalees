## L3 (pdf 28-40) — passive voice, nisba, months, إمّا
passive: past = first letter damma + the letter before the last kasra (كَتَبَ → كُتِبَ); present = first damma + letter before last fatha (يَكْتُبُ → يُكْتَبُ); the object becomes the subject (نائب الفاعل): فُتِح الباب, سُرِق كتابي, يُفتح المطعم الساعة السادسة, قُطعت يد السارق, وُجِد القلم تحت المكتب, لا تُفتح المكتبة يوم الجمعة, يُسمع الأذان في بيتنا, يجب أن يُكتب العنوان بخط واضح, خُلِق, وُلِد, قُتِل, سُئِلت, أُخِذ, ضُرِب, سُرَّ; with pronoun subject: سُئلتُ، سُئلنا، سُئلوا، سُئلن، يُسألون، تُسألين
 hollow/defective passive: وُلِد → يُولَد (waw kept) ; بُنِي ; دُعِي ; ظُنَّ
nisba: هندي عراقي سوداني ياباني كويتي نحوي تاريخي نبوي أخوي (+ ـيّ)
months (hijri calendar): المحرم صفر ربيع الأول ربيع الآخر جمادى الأولى جمادى الآخرة رجب شعبان رمضان شوال ذو القعدة ذو الحجة
إمّا ... وإمّا (either ... or): إما تزورني وإما أزورك; إبراهيم إما مريض وإما مسافر
nida with ال: الحسن → يا حسنُ, الزبير → يا زبيرُ
ثلاثمائة ... تسعمائة (+ ريال/دولار/جنيه/صفحة/طالب); اسم الجنس الجمعي: يهود→يهودي, عرب→عربي, ترك→تركي, إنكليز→إنكليزي; سمك→سمكة, شجر→شجرة, تفاح→تفاحة, عنب→عنبة, موز→موزة
Hijri-ish: الحرب مؤنثة: الحرب العالمية الأولى/الثانية, الحرب الأهلية; verbs: يستطيع (Form X; "can"), صلّى يصلّي (II defective: pray) -> EXCLUDE صلى? prayer is everyday religion vocabulary (صلاة in B1). keep as allowed? skip.
words: السارق, المسدس, المجرم, المراقب, اللص, الحذاء, ملبس/ملابس, مُعظم, جاسوس, قاعدة, ذنب, وثن(EXCLUDE), دين(EXCLUDE?), حرب, شاحنة (truck), حجر, الأنف
